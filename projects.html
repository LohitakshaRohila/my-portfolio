Python file organizer

Point it at a messy folder and it reports every file’s name, extension, and size. That’s the groundwork for sorting the chaos into order.

Pythonpathlib
$ python scan_folder.py messy_folder/
notes.txt      .txt   1.2 KB
lab_01.pdf     .pdf   844 KB
img_final.png  .png   2.3 MB
The script walks the folder with pathlib and collects each file’s name, extension, and size into a list, which later steps can use to group and move files.
